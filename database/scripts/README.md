# سكربتات تطوير واختبار (CLI)

سكربتات يدوية للتحقق من التوزيع والتسليم والتنسيق. **ليست جزءاً من تشغيل الويب.**

```powershell
php database/scripts/test-flow.php
php database/scripts/verify-plan.php
```

تتطلب قاعدة بيانات محلية وملف `.env` جاهزين (`start-local.bat` أو `php database/install.php`).
