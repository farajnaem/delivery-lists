# أرشيف — ملفات خارج منطق النظام

هنا تُجمع الملفات والأدوات **غير التابعة لتشغيل كشوفات التسليم**، للاحتفاظ بها وإعادة الاستخدام دون تشتيت جذر المشروع.

| المجلد | المحتوى |
|--------|---------|
| `tools/update-message/` | أداة مستقلة لتوليد رسائل تحديث بيانات (HTML) |
| `reports/` | تقارير PDF/DOCX وملفات تجربة مؤقتة |

**لا يعتمد** السيرفر أو تطبيق Android على هذا المجلد.

لإعادة استخدام أداة الرسائل: افتح `_archive/tools/update-message/فتح-الأداة.bat`
